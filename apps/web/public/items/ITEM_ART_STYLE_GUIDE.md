# Item Art Style Guide

Use this guide for every generated or edited item asset.

- Format: WebP, square 1:1.
- Preferred size: 512x512 for new assets.
- Background: dark cultivation-fantasy backdrop, subtle depth, no UI frame baked into the image.
- Framing: item centered and occupying about 65-80% of the canvas.
- Lighting: consistent rim light, readable silhouette, moderate contrast.
- Style: premium xianxia RPG inventory art, semi-realistic, detailed, cohesive across items.
- Avoid: text, readable characters, numbers, logo, watermark, modern props, neon-heavy effects, photorealistic mismatch, thick decorative borders.
- Rarity progression: increase material quality, rune complexity, and aura strength while keeping the same item family silhouette.
- Compatibility: do not change item keys, recipes, category gameplay, rarity, price, or schema for visual updates.
